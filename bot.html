Bot combines DiscordClient (REST) and GatewayClient (events) with a command router. @bot.cmd registers a handler under the function’s name. def echo answers !echo. A handler takes the Message and a string holding everything after the command name, empty if nothing.

_on_msg ignores messages from the bot itself. Without that, a bot that answers its own messages loops forever. It splits the message into command name and args: !echo hello world passes "hello world" as args.

You can register commands after bot.start(). @bot.cmd adds the function to a dict, and the message handler looks commands up on each message.

@bot.cmd
async def echo(msg, args): await (await msg.channel()).send(f'You said: {args}')
bot
Bot(cmds=['echo'])

The router catches errors in command handlers and appends them to bot.errors. You can inspect that list after the fact, for example in solveit. @bot.on_error registers a handler for real-time handling, such as notifying the user in Discord. Both work at the same time.
